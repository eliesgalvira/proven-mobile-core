# 08 X25519 and SUCI Profile A

Depends on: 04, 05, 07.

## Goal

- `kernel/crypto/x25519.bend`: RFC 7748 X25519 scalar multiplication over GF(2²⁵⁵−19). Limbs must keep every intermediate below 2³² (for example sixteen 16-bit limbs), because there is no U64 and `Nat` is capped at 2⁴⁸ at runtime.
- `kernel/crypto/suci.bend`: Profile A de-concealment per TS 33.501 Annex C.3.2 and C.3.4.1:
  1. ECDH with the home-network private key;
  2. ANSI X9.63 KDF with SHA-256 (32 bytes of shared info empty) → 16-byte encryption key, 16-byte ICB and 32-byte MAC key;
  3. AES-128-CTR to recover the MSIN;
  4. HMAC-SHA-256 truncated to 8 bytes as the MAC.
- The SUCI wire format and the null scheme come from TS 24.501 §9.11.3.4. Decode them here and produce a SUPI.

## Laws

- `x25519.length`: the output is 32 bytes.
- `suci.deconceal.length_checked` (advisory GHSA-vp5f-rg8g-8p7j):
  - the scheme output is accepted only if it is at least 32 (ephemeral key) + 8 (MAC) + 1 bytes;
  - the MAC is compared over all 8 bytes;
  - a mismatch returns `Fail`, never a SUPI.
- `suci.null_scheme.roundtrip`.

## Tests

RFC 7748 vectors, TS 33.501 C.4 Profile A, and the captured SUCI with the captured home-network key.

## Verify

`scripts/check.nu` (X25519 is slow in an interpreter; run its test compiled, and in the background if it exceeds 2 minutes).
