# 22 End to end with UERANSIM and eUPF

Depends on: 20, 21.

## Goal

`e2e/test.nix`, a NixOS test exposed as the flake check `e2e`. Its four VMs share one LAN (10.33.0.0/24), with the capture bench's addresses, subscriber and keys:

- `core`: the edge, which spawns the kernel (10.33.0.11, N2 and N4);
- `upf`: eUPF v0.7.2 in generic XDP mode, configured as in the eUPF research (10.33.0.20);
- `dn`: a data network that routes the UE pool back through the UPF (10.33.0.40);
- `ran`: UERANSIM's gNB and UE, with the capture's `gnb.yaml` and `ue.yaml` (10.33.0.30).

The test starts eUPF, then the core, and waits for the PFCP association. It starts the gNB and waits for NG Setup, then starts the UE and waits for `uesimtun0` to get an address from the pool. Finally it pings the data network through `uesimtun0`. A pass prints `E2E PASS`. A failure stops the check with `E2E FAIL: <step>`; every service's journal is in the VM console output above it.

The test needs a builder with KVM (the Nix system feature `nixos-test`). The flake also exposes `bend`, `kernel`, `edge` and `eupf` as packages.

## Verify

`nix build .#checks.x86_64-linux.e2e -L`
