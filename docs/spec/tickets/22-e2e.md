# 22 End to end with UERANSIM and eUPF

Depends on: 20, 21.

## Goal

`e2e/`: a Docker Compose setup and `e2e/run.sh` that:
1. Builds the core image (kernel + edge).
2. Starts:
   - eUPF v0.7.2 (privileged, XDP), configured as in the eUPF research;
   - a data-network container on N6 that answers ping;
   - UERANSIM gNB and UE, with the subscriber and the SUCI Profile A key from `test-vectors/capture/setup`.
3. Waits for the UE to register and establish a PDU session, then pings the data-network container through `uesimtun0`.
4. Prints `E2E PASS` or `E2E FAIL: <step>` and tears everything down.

Pin image digests. Reuse the capture setup in `test-vectors/capture/setup` where it fits.

## If the cloud VM can't run it

SCTP, TUN or XDP may be missing in the VM. If they are:
- write the exact failing step to `loop/blockers.md`;
- mark this ticket `needs-human` in `loop/progress.md`, with the command Elies should run locally (`e2e/run.sh`);
- move on.

Unit and replay tests already cover the logic.
