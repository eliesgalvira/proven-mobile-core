# Law changes

Each law whose statement in `kernel/LAWS.bend` differs from `main`, with why the new statement is not weaker than the old. `scripts/acceptance.py --base origin/main` fails for a changed law missing here and for an entry whose law did not change. The review before merging into `main` reads every entry; the merge deletes them.

One line per law: `` - `law.name`: why ``.

- `smf.releases.sent`: an exact restatement: its first two conjuncts stay word for word; the third states `Gs.Gsm.n2_release`'s outcome exactly, now with the action `PduRelease` that carries the PDU Session Release Command visibly instead of `UeSend` with the PDU already built, and a fourth says that action renders the very frame the old `UeSend` did.
- `amf.handover.guarded`: every clause of main stays word for word; one is added, that a step stopping timer k, which no session holds, leaves no handover pending under k. Its premise only sets aside a session's guard under the same key, which every reachable state rules out (`state.ids.free`: context keys odd, session keys even).
- `smf.establish.failure_releases`: every conjunct of main stays word for word, with one more variable (`ctx`); the three failures past the Accept that drop a session (its guard while being set up, the Session Modification refused or unanswered) gain a conjunct: when the session's UE holds a NAS context, the step's first action is the PDU Session Resource Release Command to its gNB with the PDU Session Release Command inside (`Gs.Gsm.tells_gnb`).
- `amf.path_switch.stored_capabilities`: an exact restatement extended to the new actions: every conjunct of main stays word for word but the one stating `Gs.Gsm.switch_end`'s outcome, which still states it exactly; that outcome now also sends, after the acknowledgement, PDU Session Release Command for each session released (`Gs.Gsm.releases`), and the context's phase holds the NAS context they leave where it held the one before them.
- `amf.ue_key.unknown`: the five conjuncts of main stay word for word, with one more variable (`items`); a sixth says the same of a PDU Session Resource Release Response carrying an AMF-UE-NGAP-ID of 2^32 or more: the state as it was, Error Indication and a log line.
